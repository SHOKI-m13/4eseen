# 📊 4Eseen — 財務分析Webアプリ

就活生・個人投資家・中小企業経営者向けの財務諸表分析ツールです。  
CSVをアップロードするだけで、財務指標の自動計算・グラフ表示・分析コメント・シナリオ分析を行います。

---

## 特徴

- **15種類以上の財務指標**を自動計算（成長性・収益性・安全性・効率性・CF）
- **単なる数値表示ではなく、1つの変化に対して複数の仮説を提示**する分析コメント
- **3シナリオ分析**（良い・標準・悪い）で将来を多角的に検討
- **ダークテーマのプロ仕様UI**（タブ・KPIカード・ゲージ・レーダーチャート）
- 列が一部欠けていても動作する**柔軟なCSV対応**

## セットアップ

### 必要環境

- Python 3.9 以上
- pip

### インストール

```bash
git clone https://github.com/your-username/financial_analyzer.git
cd financial_analyzer
pip install -r requirements.txt
```

### 起動

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動で開きます。

## CSVフォーマット

以下の列名を使用してください（数値は**百万円単位**推奨）。  
列が一部なくても動作します。

| 列名（英語） | 意味 |
|---|---|
| `company` | 会社名（必須） |
| `year` | 年度（必須） |
| `sales` | 売上高 |
| `operating_profit` | 営業利益 |
| `ordinary_profit` | 経常利益 |
| `net_income` | 純利益 |
| `total_assets` | 総資産 |
| `equity` | 自己資本 |
| `liabilities` | 負債合計 |
| `current_assets` | 流動資産 |
| `current_liabilities` | 流動負債 |
| `cash` | 現金・預金 |
| `accounts_receivable` | 売上債権 |
| `inventory` | 棚卸資産 |
| `fixed_assets` | 固定資産 |
| `interest_bearing_debt` | 有利子負債 |
| `operating_cash_flow` | 営業キャッシュフロー |
| `investing_cash_flow` | 投資キャッシュフロー |
| `financing_cash_flow` | 財務キャッシュフロー |
| `employees` | 従業員数 |

サンプルCSVは `sample_data.csv` を参照してください（3社・5期分のサンプルデータ入り）。

## 計算する財務指標

### 成長性
- 売上高成長率・営業利益成長率・純利益成長率・総資産成長率

### 収益性
- 営業利益率・純利益率・ROA・ROE

### 安全性
- 自己資本比率・負債比率・流動比率・有利子負債依存度

### 効率性
- 総資産回転率・売上債権回転率・棚卸資産回転率

### キャッシュフロー
- 営業CFマージン・フリーキャッシュフロー・営業CF vs 純利益
